Cara saya bekerja

Skeptis secara default, rapi secara dokumentasi.

Saya bisa salah, Anda juga bisa salah — jadi kita sama-sama mengoptimalkan akurasi. Enam prinsip yang saya pegang di setiap proyek:

01 / verify

Cek ulang, jangan asumsi

Angka, fakta, dan asumsi dihitung ulang dan ditunjukkan langkahnya. Inkonsistensi dan data yang hilang ditandai sebelum menyimpulkan.

02 / confidence

Jujur soal tingkat keyakinan

Pisahkan yang saya tahu, yang saya simpulkan, dan yang belum pasti — lengkap dengan cara memverifikasinya.

03 / audit

Audit-friendly by design

Setiap perubahan di-commit, setiap rencana disertai dampak dan langkah rollback. Audit trail bukan tambahan belakangan, tapi bagian dari desain awal.

04 / least-privilege

Akses seminimal mungkin

Role-based access, auth hardening, scope OAuth paling sempit. Kalau tidak perlu akses, jangan diberi akses.

05 / compliance

Kalau ragu, pilih jalur patuh

Legalitas dan perlindungan perusahaan di atas kecepatan. Setiap keputusan berisiko didokumentasikan beserta trade-off-nya.

06 / teach

Bikin proses yang bisa diulang

Output terstruktur — tabel, checklist, template — yang bisa langsung dipakai, plus penjelasan kenapa, supaya tim ikut paham.

Self-hosted multi-agent AI server

personal · aktif · 2026

Server pribadi yang menjalankan beberapa AI agent berbasis OpenClaw. Tiap agent punya peran sendiri: asisten umum, pencatat keuangan pribadi ke Notion, asisten riset IT governance, dan admin server.

  • Membersihkan secret yang tersebar di 37 file dan memindahkannya ke satu env file dengan permission 600, lalu merotasi API key
  • Setiap workspace agent di-git init, jadi semua perubahan konfigurasi tercatat dan bisa di-rollback
  • Least privilege per agent: tool deny-list, kebijakan exec, dan model fallback
  • Kajian upgrade versi: memetakan plugin pihak ketiga yang berisiko rusak sebelum upgrade dilakukan

Insiden: sub-agent yang membuat data sampah

case study · Okt 2026

Sebuah agent mendelegasikan perhitungan ke sub-agent yang ternyata tidak punya akses baca. Sub-agent itu mencoba-coba, lalu membuat 10 entri sampah di database Notion. Saya menyusun timeline per menit dari log, menelusuri akar masalahnya, dan memastikan semua entri sampah sudah diarsipkan.

  • Remediasi: blokir sub-agent dan code_execution untuk agent tersebut
  • Dokumentasikan pola query yang benar, sehingga waktu jawab turun dari ±7 menit menjadi target ±1 menit

Akses remote aman untuk MCP server

desain · 2026

Rancangan cara membuka MCP tools ke luar jaringan tanpa membuka server: Tailscale Funnel → nginx token gate → container MCP. Hardening dilakukan bertahap: SSH key-only, ACL tag, baru setelah itu funnel.

  • Analisis Cloudflare Tunnel vs Tailscale: WAF L7, idle timeout 100 detik, risiko double-hop
  • Rekomendasi: satu jalur per layanan, ditambah keepalive untuk tool yang berjalan lama
